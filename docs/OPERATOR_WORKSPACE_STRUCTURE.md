# Operator Development Workspace Structure

Operator Development is one top-level Zero Command workspace with internal hubs:

- Overview
- Learning
- Execution
- Tasks
- Reflection
- Challenges
- Achievements
- Stats / History / Analytics

Learning, Execution and Tasks are not peer workspaces beside Operator Development. They are systems inside it.

## Event relationship

Task created -> planned execution
Task completed -> Discipline evidence
Execution recorded -> capability/stat evidence
Reflection attached -> learning and Spirit evidence
Achievement unlocked -> validated milestone
