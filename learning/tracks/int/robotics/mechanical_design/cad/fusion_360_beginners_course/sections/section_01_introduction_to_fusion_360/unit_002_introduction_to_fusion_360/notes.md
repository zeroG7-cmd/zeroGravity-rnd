# Notes

## Fusion 360 basics
- Fusion 360 is a cloud-based CAD software.

## Data Panel
- The Data Panel is where your project files live.
- Course content downloaded earlier can be added into a new project from here.

## Local vs. cloud storage
- Similar concept to saving files on a local network drive, but the difference 
  is that files are saved to your Autodesk cloud account instead.
- Files can still be saved locally if needed.
- To save locally: **File → Export**, then pick the format you want.

## Loading and working with files
- Click and drag a file into the workspace to load it.
- Cloud saves open your default browser automatically — useful for sharing 
  your work with others.
