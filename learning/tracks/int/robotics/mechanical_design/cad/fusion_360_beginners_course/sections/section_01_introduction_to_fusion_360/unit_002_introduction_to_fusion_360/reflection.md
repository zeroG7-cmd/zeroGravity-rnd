# Reflection
Went through the Data Panel and cloud-saving workflow, created a project 
folder, uploaded course content into it, and tested loading a part by 
dragging it into the workspace.

The bit that actually landed for me: cloud saving means I'm not tied to 
working on my local machine. If I want to keep working on Shadow Mark 1 & 2 
away from my desktop, I still can, everything's on my Autodesk cloud 
account, not just sitting on this PC. It also means I could bring 
collaborators in on the same files without emailing zip files back and forth.

The Data Panel itself is a solid way to keep projects organised, one 
folder per project, version history tracked automatically, so I'm not 
manually naming files "v2_final_FINAL" like I would on a local drive.

Next step: keep this course's practice files in their own project folder, 
separate from the real zeroGravity/Shadow work, so they don't get mixed up 
as things build up.
