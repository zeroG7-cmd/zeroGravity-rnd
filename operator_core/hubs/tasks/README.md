# Operator Task Hub

Tasks belong to Operator Development rather than being a top-level Zero Command workspace.

They represent **planned execution** and can later generate evidence for:

- Discipline: consistency, planning, task completion and accountability.
- Other main stats selected by the task.
- Execution records when a completed task produces meaningful evidence.

`data/tasks.json` is local runtime data. The first version is intentionally simple; later versions can add projects, due dates, recurrence, priorities and automatic execution receipts.
